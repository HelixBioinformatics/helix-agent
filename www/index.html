Open Terminal from your applications menu. Use wget or curl installed through your distribution’s package manager.

Instala el agente

Install the agent

Con wget, descarga el instalador y ejecútalo solo si la descarga termina correctamente.

With wget, download the installer and run it only after a successful download. 

wget -O helix-install.sh https://helixbiolab.github.io/helix-agent/install && bash helix-install.sh
¿Prefieres curl?Prefer curl?

Usa la versión del sistema. En Ubuntu o Debian puedes instalarla con sudo apt install curl. La ruta completa evita usar por accidente la versión de Snap.

Use the system version. On Ubuntu or Debian, install it with sudo apt install curl. The full path avoids accidentally selecting the Snap version. 

/usr/bin/curl -fL -o helix-install.sh https://helixbiolab.github.io/helix-agent/install && bash helix-install.sh

Si falta WSL, el instalador te guía para habilitarlo. Ese paso requiere permisos de administrador y puede pedir un reinicio. Luego, vuelve a ejecutar el comando.

If WSL is missing, the installer guides you through enabling it. This requires administrator rights and may need a restart. Then run the command again.

El agente se instala en tu carpeta personal. En Linux y macOS, este paso no requiere sudo. Puedes revisar el script de Linux y macOS o el de Windows antes de ejecutarlo.

The agent installs in your home folder. On Linux and macOS, this step does not need sudo. You can read the Linux and macOS script or the Windows script before running it.

¿curl te falla en Ubuntu?

Trouble with curl on Ubuntu?

Si lo instalaste mediante Snap, sus restricciones de acceso a archivos pueden interferir con la instalación. Usa wget desde APT o el curl del sistema. El instalador admite ambos y evita los ejecutables de Snap.

Snap’s file access restrictions can interfere with installation. Use wget from APT or the system curl. The installer supports both and skips Snap executables.

Antes de empezar

Before you begin

¿Necesito un modelo o una suscripción?Do I need a model or a subscription?

Helix Agent no incluye un modelo propio. Conecta un proveedor con tus credenciales; la disponibilidad y el costo dependen del proveedor y del modelo que elijas.

Helix Agent does not include a model. Connect a provider with your credentials; availability and cost depend on your provider and chosen model.

¿Qué herramientas necesito para analizar mis datos?Which tools do I need to analyze my data?

Depende del análisis. Los flujos de Nextflow requieren Java y pueden usar Docker, Apptainer o Conda. Este comando revisa tu equipo y sugiere cómo instalar lo que falte, sin hacer cambios:

It depends on your analysis. Nextflow workflows require Java and may use Docker, Apptainer or Conda. This command checks your machine and suggests how to install missing tools without making changes: 

helix debug env
¿Cómo verifico una descarga manual?How do I verify a manual download?

Descarga también SHA256SUMS de la misma versión y guárdalo junto al archivo. Ejecuta el comando desde esa carpeta. Si no descargaste todos los archivos, aparecerán avisos por los que faltan; comprueba que el tuyo indique OK.

Download SHA256SUMS from the same release and save it beside the archive. Run the command from that folder. Missing archives may produce warnings; check that your downloaded file reports OK.

En Linux:

On Linux:

sha256sum --check --ignore-missing SHA256SUMS

En macOS:

On macOS:

shasum -a 256 --check SHA256SUMS
¿Cómo actualizo sin desinstalar? How do I update without uninstalling?

Vuelve a ejecutar el instalador de esta página. Reemplaza el ejecutable y conserva la configuración, credenciales y sesiones. Después abre una sesión nueva y ejecuta helix --version. No necesitas desinstalar. Si SSH no encuentra el comando, usa ~/.helix/bin/helix --version.

Run this page's installer again. It replaces the executable and retains settings, credentials and sessions. Then start a new session and run helix --version. You do not need to uninstall. If SSH cannot find the command, use ~/.helix/bin/helix --version.

La próxima versión incorpora helix upgrade y helix upgrade --check. El binario 0.3.0 todavía requiere el instalador.

The next version adds helix upgrade and helix upgrade --check. The 0.3.0 binary still requires the installer.

¿Puedo instalar una versión específica o compilar el código?Can I install a specific version or build from source?

Sí. Después de descargar el instalador, ejecútalo con bash helix-install.sh --version X.Y.Z, reemplazando X.Y.Z por una versión publicada. Para compilarlo, sigue la guía del repositorio.

Yes. After downloading the installer, run bash helix-install.sh --version X.Y.Z, replacing X.Y.Z with a published version. To build from source, follow the repository guide.

¿Qué queda registrado del análisis?What does the analysis record?

El agente puede generar un dossier, un registro del protocolo, un recuento del trabajo y manifiestos de archivos. Sirven para revisar lo realizado y sus límites. Encontrarás los detalles en la documentación de los cuatro artefactos.

The agent can produce a dossier, a protocol ledger, a work tally and file manifests to help review the work and its limits. Read about the four artifacts.
