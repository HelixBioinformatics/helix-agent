# Entrega real para evaluación experta

Enviar `Helix-evaluacion-experta.zip`. Al extraerlo se obtienen `evaluacion.xlsx` y `datos/`; deben mantenerse juntos. El Excel contiene instrucciones y enlaces relativos, sin asuntos internos de infraestructura, presupuesto o coordinación técnica.

La experta comienza en Inicio, sigue Guía y Alcance, y utiliza el Índice para navegar por las 70 solicitudes. Completa su referencia y dos paráfrasis humanas por intención factible. Puede entregar avances parciales. Es la etapa previa a ejecutar y juzgar las salidas de Helix. Las conversaciones reales para kappa se entregarán después.

El conjunto contiene 50 propuestas con datos públicos de proteínas humanas y 20 peticiones para evaluar límites. La factibilidad final, las referencias y las paráfrasis están pendientes de revisión humana. No se presentan borradores como etiquetas recibidas.

Trazabilidad, decisiones, restricciones y reproducción: [registro del corpus](../../../evaluation/trp/corpus-20260930/README.md). No hace falta enviar ese registro a la experta.
